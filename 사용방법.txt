영수증 정리 · Receipt Studio

실행: ReceiptStudio-v4.exe를 더블클릭하세요. ZIP 배포본은 압축을 먼저 풀어주세요.
Windows 10/11 64비트용입니다. 영수증 처리에 인터넷 연결이 필요 없습니다.
OCR 엔진과 한글/영어 학습 데이터가 실행 파일에 포함됩니다.
OCR 구성 요소 오류가 나는 PC는 Microsoft Visual C++ 2015–2022 런타임(x64)이 필요할 수 있습니다.
공식 설치 파일: https://aka.ms/vs/17/release/vc_redist.x64.exe
다른 PC로 옮길 때도 EXE 파일 하나를 복사하면 됩니다.

1. [이미지 추가]에서 여러 영수증을 선택하거나 창으로 파일을 끌어놓습니다.
2. 왼쪽에서 A4 세로/가로, 페이지당 최대 개수(1~24), 여백과 간격을 정합니다.
   기본 출력 폭은 60mm입니다. 높이는 각 영수증의 원래 비율대로 유지합니다.
   공간이 부족하면 영수증을 작게 줄이지 않고 다음 페이지로 보냅니다.
3. 상단 제목을 직접 수정합니다.
   기본 제목: 2026년 10월 지출영수증 이재원 사원
4. 오른쪽 인쇄 미리보기는 항상 표시되고 변경 사항이 자동 반영됩니다.
   여러 페이지일 때 ‹ / › 버튼으로 이동합니다.
5. 영수증 목록에서 한 장을 선택하면 회전, 자르기, 순서 변경,
   복제, 삭제가 가능합니다. 원본 이미지 파일은 변경하지 않습니다.
6. [파일로 저장]에서 PDF, PNG 또는 JPEG를 선택합니다.
   PDF는 전체 페이지를 한 파일로 저장합니다.
   PNG/JPEG는 여러 페이지일 때 _01, _02 등의 번호를 붙여 저장합니다.
   출력 해상도는 300 DPI입니다.
7. [인쇄]에서 프린터와 페이지 범위를 선택합니다. A4 용지를 사용하세요.
8. [작업 저장]은 편집 가능한 .receipt 파일을 저장합니다.
   이미지와 설정이 함께 들어 있으므로 다른 PC에서도 [작업 열기]로 이어서 편집할 수 있습니다.

여러 영수증이 이미 한 장으로 합쳐진 이미지:
이미지를 추가한 뒤 필요한 장수만큼 [복제]하고,
각 항목의 [자르기]에서 해당 영수증 영역만 드래그해 적용하세요.
개별 영수증 사진을 바로 추가하는 방법이 가장 간단합니다.

프로그램은 이미지를 외부 서버로 전송하지 않습니다.
PDF는 출력용 이미지 기반 문서이며 PDF 자체의 텍스트 검색은 지원하지 않습니다.
프린터의 인쇄 불가능 영역에 따라 가장자리가 달라질 수 있으므로
기본 여백 10mm를 권장합니다.

개발 소스 및 상세 안내: https://github.com/dpfmaptm1534/Receipt-Studio
빌드: 저장소의 build.ps1 또는 README의 .NET 8 SDK 빌드 명령을 사용하세요.
검증: ReceiptStudio-v4.exe --self-test
검증 결과: 실행 파일 옆 test-output 폴더의 result.txt

결제일 OCR과 정렬
1. 영수증을 추가하고 미리보기 위의 [전체 OCR]을 누릅니다.
   한 장만 다시 인식하려면 목록에서 선택한 뒤 [선택 OCR]을 누릅니다.
2. 목록에 날짜가 표시됩니다. OCR이 읽은 날짜는 'OCR 추정'으로 표시됩니다.
3. [날짜 확인/수정]에서 원본 이미지, 날짜 후보, 인식한 전체 텍스트를 확인합니다.
   결제일을 직접 입력하거나 후보를 선택한 후 [날짜 적용]을 누릅니다.
   날짜 체크를 해제하면 '날짜 미지정'으로 저장됩니다.
4. [날짜 ↑]는 오래된 날짜부터, [날짜 ↓]는 최신 날짜부터 정렬합니다.
   날짜 없는 항목은 두 경우 모두 맨 뒤에 놓습니다. 같은 날짜는 기존 순서를 유지합니다.
   정렬 결과가 미리보기와 인쇄/이미지/PDF 출력에 그대로 반영됩니다.
5. 작업 저장에는 인식 텍스트, 후보 날짜, 수정한 결제일도 함께 저장됩니다.
   기존 버전의 .receipt 작업 파일도 열 수 있습니다.

OCR 중에도 미리보기와 용지 설정을 사용할 수 있습니다.
[중지]는 현재 이미지 인식이 끝난 뒤 나머지 작업을 중지합니다.
직접 적용한 날짜는 재인식해도 유지됩니다. 이미지를 자르면 기존 인식 정보는 초기화됩니다.
여러 결제일이 있거나 11/09/2026처럼 일/월 순서가 불명확하면 확인이 필요합니다.
흐리거나 기울어진 사진은 틀리게 인식할 수 있으므로 출력 전 날짜를 확인하세요.
여러 영수증이 합쳐진 이미지에는 날짜를 하나로 정할 수 없습니다. 각각 잘라 인식하세요.
현재 자동 추출 항목은 결제일입니다. 상호/금액 등은 인식 전체 텍스트로 참고할 수 있습니다.

무료 오픈소스: Tesseract OCR 및 .NET wrapper (Apache-2.0),
Leptonica (BSD), InteropDotNet (MIT). 상세 고지와 라이선스는 licenses 폴더에 있습니다.
OCR 학습 데이터와 엔진은 최초 인식 시 사용자 LocalAppData/ReceiptStudio/ocr-5.2.0에 캐시됩니다.

v3: 글씨 크기를 유지하는 배치
- [기본 출력 폭 (mm)]으로 전체 영수증의 기준 크기를 정합니다 (30~150mm).
- 한 장의 글씨가 작으면 왼쪽 목록에서 해당 영수증을 선택합니다.
  미리보기 위 [기본 폭 사용] 체크를 해제하고 [선택 영수증 폭 (mm)]을 늘리세요.
  예: 일반 영수증 60mm, 글씨가 작은 휴대폰 캡처 75mm.
- 폭을 바꾸면 높이도 원본 비율에 맞춰 함께 바뀝니다. 늘이거나 잘라서 맞추지 않습니다.
- 페이지당 개수는 최대치입니다. 실제 장수는 크기와 용지 여유 공간에 따라 적을 수 있습니다.
- 한 페이지보다 긴 영수증은 크기를 줄이지 않고 여러 페이지로 나눠 출력합니다.
  하단에 '긴 영수증 나눔'과 조각 번호를 표시하며, 모든 원본 내용이 순서대로 이어집니다.
- 영수증별 출력 폭도 작업 파일에 저장됩니다. 기존 작업 파일은 기본 폭 60mm로 열립니다.
- 사진의 픽셀 해상도만으로 실제 종이 크기나 글자 크기를 알 수는 없습니다.
  출력 폭을 조절하면서 미리보기로 글씨 크기를 확인하세요.

v4: 미리보기에서 마우스로 크기 조절
1. 미리보기 안에서 영수증을 직접 클릭합니다.
2. 파란 선택 테두리의 모서리 네모를 마우스로 잡아 끕니다.
3. 바깥으로 끌면 커지고 안쪽으로 끌면 작아집니다. 원래 비율은 유지됩니다.
4. 마우스를 놓으면 새 크기로 자동 배치합니다. 공간이 부족하면 다음 페이지로 넘어갑니다.
   드래그 중 파란 숫자에 출력 폭(mm)이 표시됩니다. 조절 범위는 30~150mm입니다.
5. 드래그 중 Esc를 누르면 변경을 취소합니다.
미리보기에서 조절하면 해당 영수증의 '기본 폭 사용'은 자동으로 해제됩니다.
파란 테두리와 조절점은 편집용 표시이며 인쇄나 저장 파일에는 나오지 않습니다.
미리보기의 빈 곳을 클릭하면 선택이 해제됩니다.
여러 페이지로 나뉜 긴 영수증도 한 부분을 조절하면 영수증 전체의 출력 폭이 바뀝니다.
